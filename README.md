# Machine Universelle

## Documentation

Une documentation est disponible pour le projet, se réferrer à `docs.pdf`.

## Les machines

Le code des machines implémentées dans le cadre du projet se trouve dans le répertoire `machines/` et sont au format `.txt`.

## Tests

Pour lancer le test de chacune des tâches du projet, lancer la commande suivante :

```sh
make q<x>
# x entre 1 et 10.
```

**Exemple** :

Pour tester la tâche 8 qui correspond à afficher le codage en binaire de certaines machines de Turing, il faut lancer la commande suivante :

```sh
# version abrégée :
make q8

# version complète pour voir le codage binaire en entier :
make q8_all
```
