# sortie : x * y (sur r1)

# la machine va déplacer x dans r2, et copier y dans r3
# puis elle va copier le mot y x fois dans r1

# replace la tête de r2 à gauche

qLEFT(2),_11;qLEFT(2),_11,-<-
qLEFT(2),__1;qSTEP,__1,--<

# pour ne pas multiplier par x + 1
